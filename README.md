# Project-3:RandomPasswordGenerator

Project Description:
A Python tool that generates secure random passwords based on user-defined password length.

Features:
Random password generation,
Supports letters, numbers, and special characters,
and User-defined password length.

Concepts Used:
Python Modules,
secrets Module,
string Module,
String Manipulation,
and Loops.

What I Learned:
Importing and using Python libraries,
Generating random secure data,
Basic security tool development,
and String handling in Python.
